# Writely 0.4.0-alpha.1 – unveröffentlichter Prüfstand

Dieses Update wird zunächst als Pull Request und Windows-CI-Artefakt bereitgestellt. Ein GitHub-Release wird erst nach ausdrücklicher Freigabe veröffentlicht.

Neu: Papierkorb und sichere Bibliotheksrevisionen, pro Dokument begrenzter Verlauf mit Vorschau, validierte lokale Bibliotheksbackups, Live-Suche mit isolierter Regex-Ausführung, Bibliotheks-Volltextsuche, gebündelte Offline-Rechtschreibung für Deutsch/Englisch mit Benutzerwörterbuch, dynamisches Inhaltsverzeichnis und echte Fuß-/Endnotenknoten.

DOCX und ODT enthalten native Noten; PDF/HTML geben verlinkte Noten am Ende aus. Verzeichnis-Seitenzahlen sind noch offen; konkrete Formatwarnungen erscheinen vor dem Export. Neue Dateien verwenden Schema 2; Schema 1 wird ausdrücklich migriert.

[Umgesetzte Funktionen, Architektur, Dateibereiche, Tastatur, Tests und Grenzen](UPDATE-0.4.md).

Die bisher veröffentlichte Version ist [0.3.0-alpha.1](RELEASE-0.3.md). Ältere Hinweise: [0.2.1](RELEASE-0.2.1.md), [0.2](RELEASE-0.2.md).
